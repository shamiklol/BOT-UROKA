# Личный бот продуктивности

Telegram-бот для одного человека: деньги, задачи и планёрка, идеи, привычки, утренняя сводка и вечерний итог.
Пишете обычным текстом — бот сам понимает, что это.

| Вы пишете | Бот делает |
|---|---|
| `кофе 25к`, `такси 30 000`, `вчера обед 85к`, `$20 подписка` | карточка расхода: категория, счёт, сумма → «Сохранить» |
| `+8 млн зарплата` | карточка дохода |
| `завтра в 15:00 созвон с Азизом`, `в пятницу отправить отчёт`, `срочно оплатить интернет` | карточка задачи, напоминание в указанное время |
| любая мысль, `идея: …` | сохраняет во входящие, можно превратить в задачу |
| голосовое | расшифровывает и разбирает так же (нужен `OPENAI_API_KEY`) |

Бот запоминает категории: если один раз выбрать для «чучвара» категорию «Продукты», дальше она подставится сама.

## Команды

`/today` задачи на сегодня · `/plan` планёрка (3 главные задачи) · `/tasks` все задачи ·
`/ideas` входящие · `/habits` привычки, `/habit Зарядка 07:30` · `/report` отчёт · `/balance` счета ·
`/setbalance Карта 2 млн` · `/undo` отменить последнюю трату · `/summary` / `/review` сводки сейчас ·
`/settings`, `/morning 07:30`, `/evening 22:00`, `/budget 6 млн` · `/t12`, `/i5` — открыть задачу или идею.

Автоматически: утренняя сводка (по умолчанию 08:00), вечерний итог (21:30), напоминания о задачах и привычках.
Курс доллара берётся у ЦБ Узбекистана (cbu.uz).

## Деплой на Railway

1. **New Project → Deploy from GitHub repo** → выберите этот репозиторий.
2. В проекте: **+ New → Database → PostgreSQL**.
3. В сервисе бота → **Variables**:
   - `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`
   - `TZ` = `Asia/Tashkent`
   - по желанию `ANTHROPIC_API_KEY` (ИИ-разбор сложных фраз) и `OPENAI_API_KEY` (голосовые)
4. После деплоя напишите боту `/start` — он пришлёт ваш Telegram ID. Добавьте переменную `OWNER_ID` с этим числом.
   После перезапуска бот отвечает только вам.

Бот работает через long polling, домен и вебхук не нужны.

## Локальный запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements-dev.txt
copy .env.example .env          # впишите BOT_TOKEN
python -m bot
```

Тесты: `pytest`.

## Устройство

```
bot/
  __main__.py        запуск, роутеры, меню команд
  config.py          настройки из переменных окружения
  scheduler.py       сводки и напоминания (цикл раз в 30 с, состояние в базе)
  middlewares.py     доступ только владельцу
  ui.py              форматирование и клавиатуры
  db/                модели SQLAlchemy и создание таблиц
  services/
    parser.py        разбор сумм, дат, категорий без ИИ
    ai.py            разбор через Claude, если правила не уверены
    currency.py      курс ЦБ
    repo.py          отчёты, балансы, списки задач, серии привычек
    summaries.py     утренняя сводка и вечерний итог
    voice.py         распознавание голосовых
  handlers/          команды и кнопки по разделам
```

ИИ подключается только когда простых правил не хватило, поэтому обычные траты и задачи не тратят токены.
Модель задаётся переменной `CLAUDE_MODEL` (по умолчанию `claude-opus-5-5`; для экономии можно `claude-haiku-5-5`).
